## 🧩 Problem-Solving Approach

For every DSA problem, I try to follow these steps:

1. Understand the problem
2. Identify the input and output
3. Think about edge cases
4. Write the brute-force approach
5. Optimize the solution
6. Analyze time complexity
7. Analyze space complexity
8. Write clean Java code
